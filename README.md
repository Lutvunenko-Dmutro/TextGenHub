## 📖 Про проєкт

**TextGenHub** — це веб-застосунок, який дозволяє згенерувати текст на основі обраної теми, бажаної довжини, стилю та тону. Спочатку це була проста базова сторінка, але зараз проєкт пройшов **повний дизайн-рефакторинг**.

### 🌟 Що нового:
1. **Premium Dark Mode Design:** Повністю новий темний інтерфейс кольору `Midnight Blue` з ефектом матового скла (Glassmorphism) та неоновим фіолетово-рожевим світінням на фоні.
2. **Typewriter Effect:** Тепер згенерований текст не просто з'являється миттєво, а плавно "друкується" на екрані, імітуючи роботу реального Штучного Інтелекту!
3. **Fake AI Loader:** Додана анімована стадія завантаження ("Аналіз семантичного ядра...", "Синтез креативних патернів..."), що створює враження серйозної обробки даних.
4. **Copy-to-Clipboard:** Зручна кнопка швидкого копіювання згенерованого результату.

## 🚀 Як запустити (Умови активації)

Цей проєкт використовує **локальний Штучний Інтелект (Ollama)** для повної приватності та безлімітної генерації без жодних API ключів. Оскільки браузер (з міркувань безпеки) блокує запити з локального файлу до локального сервера, необхідно правильно запустити Ollama.

**Крок 1: Встановлення (один раз)**
1. Завантажте та встановіть [Ollama](https://ollama.com/).
2. Відкрийте термінал і завантажте модель `llama3.2`:
   ```bash
   ollama run llama3.2
   ```

**Крок 2: Запуск (щоразу перед використанням)**
Якщо ви просто відкриєте `index.html`, запит буде заблоковано (CORS error). Щоб дозволити браузеру підключатись до Ollama, відкрийте PowerShell і виконайте:
```powershell
# Дозволяємо підключення звідусіль (вирішує помилку CORS)
$env:OLLAMA_ORIGINS="*"
# Запускаємо сервер
ollama serve
```

**Крок 3: Використання**
Після того, як сервер `ollama serve` запущено, просто відкрийте файл `/app/index.html` у вашому браузері подвійним кліком і генеруйте текст!

- `/app/script.js` — Логіка генерації, словники фраз, ефекти друку та копіювання.
- `/interaction_diagram_project/` — Текстові діаграми з оригінального релізу.
